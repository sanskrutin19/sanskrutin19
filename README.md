## Featured work

### Tender Intelligence: offline RAG that cites its source · [Live app →](https://promptivo.live/app)
`Python` `LangChain` `FastAPI` `Ollama` `ChromaDB` `SQLite FTS5` `MCP`

- Answers eligibility, EMD, scope, risk and penalty questions with the **exact source sentence and page number**, cutting tender analysis from hours to minutes.
- Hybrid search (vectors + keywords) with rank fusion and cross-encoder reranking; evaluated on a golden question set.
- Go/No-Go, risk-finder and contradiction-finder modules; Redmine integration via MCP. Runs fully offline for confidential documents.

### SecureChat: end-to-end encrypted messaging
`React 18` `XMPP/ejabberd` `OMEMO2 (Signal Protocol)` `WebRTC` `PostgreSQL` `Docker` `Capacitor`

- Double Ratchet encryption across messages, media and calls; local-first storage for offline history.
- WebRTC voice and video, and encrypted file sharing up to 500 MB via chunked AES-GCM; Android and iOS from one codebase.
